# JARVIS AI Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `jarvis-core`, a local Electron app with a model-agnostic chat + voice core, and a reactive "neural lattice" orb in the JARVIS wallpaper driven by its events.

**Architecture:** `src/core/` is plain CommonJS Node (no Electron) holding bus, config, sessions, provider/engine/tool registries, orchestrator, VAD, voice controller and the HTTP/SSE bridge; it is tested with `node --test`. `src/main/` is a thin Electron shell (tray, hotkeys, windows, IPC). The wallpaper (`jarvis-desktop/wallpaper`) subscribes to `/ai/stream` and draws events.

**Tech Stack:** Node 22, Electron ^45 (same as sysmon-widget), CommonJS, vanilla JS/CSS renderer, three.js 0.170 (existing wallpaper vendor copy), PowerShell 5.1 + `System.Speech` for starter speech engines, `node:test` + `node:assert/strict`.

**Spec:** `jarvis-core/docs/specs/2026-11-09-ai-core-design.md`

## Global Constraints

- No language/STT/TTS model is chosen or bundled. Only `NullProvider` ships. `FakeProvider` lives in `test/` only.
- Local only: every server binds `127.0.0.1`; no outbound network except `127.0.0.1:47800` (sysmon).
- Bridge port 47801, fallback 47802–47806. Host/Origin checks copied from `sysmon-widget/src/main/bridge.js:20` (`okOrigin`) and its `okHost`.
- Data dir `%APPDATA%/jarvis-core/` → `config.json`, `history/*.json`, `history/broken/`.
- Hotkeys: chat `Control+Space`, voice `Control+Shift+Space`. `Esc` hides chat / stops reply / cuts speech.
- Provider silence timeout 60 000 ms. Max 5 tool rounds per turn. VAD silence 800 ms, max capture 30 000 ms.
- `level` events ≤ 30 Hz on the bridge. Lattice ≤ 400 nodes, ≤ 64 live sparks.
- Electron windows: `contextIsolation: true`, `nodeIntegration: false`, preload only.
- Renderer and wallpaper are plain scripts (no bundler), matching the existing wallpaper.

## Review Focus

1. **Speaker echo triggers barge-in** — while speaking, mic VAD threshold is raised ×3 so TTS through speakers doesn't cut itself off. Test in Task 11.
2. **Second send while a turn is streaming** — `send()` rejects with `BUSY` instead of interleaving two turns into one session. Test in Task 5.
3. **Hotkey already taken** (e.g. PowerToys owns `Control+Space`) — registration failure is logged and shown in tray tooltip + settings, app still starts. Test in Task 7 (`registerHotkeys` returns failures).
4. **Wallpaper loaded before the app / app restarted** — `ai-link.js` re-probes ports with backoff forever; orb shows idle, never errors. Test in Task 9.
5. **Huge pasted message / long history** — orchestrator sends at most the last messages fitting `contextMax` (chars/4 estimate) when the provider reports one; session file still keeps everything. Test in Task 5.

### Task 11: VAD + voice controller

**Files:** Create `src/core/voice/vad.js`, `src/core/voice/engines.js`, `src/core/voice/controller.js` · Test `test/vad.test.js`, `test/voice-controller.test.js`

**Interfaces:**
- Produces: `createVad({ silenceMs = 800, maxMs = 30000, minLevel = 0.02 }) → { push(pcm: Int16Array, sampleRate) → 'none'|'start'|'end'|'max', rms: number, setGain(mult), reset() }`. Threshold = `max(minLevel, noiseFloor × 3) × gain`; noise floor = mean RMS of first 300 ms.
- Produces: engine registries per spec §3 (`createRegistry` from T3) with `NoneStt/NoneTts/NoneWake` fallbacks (`status().ready:false`).
- Produces: `createVoiceController({ bus, orchestrator, engines: { stt, tts, wake }, getConfig, getSessionId }) → { listen(), feed(pcm, sampleRate), cancel(), speaking: boolean }`
- Flow: `listen()` → `state listening`; `feed` → `level {source:'mic'}` + VAD; on `end|max` → `stt.transcribe` → `orchestrator.send(..., {source:'voice'})` → `tts.speak` → `state speaking` → `idle`. During speaking VAD gain ×3; `start` → cancel TTS, `listen()` *(Review Focus 1)*. `cancel()` stops whatever is running. Empty transcript → back to idle with no turn. STT/TTS failure → text-only + one `log` event.

- [ ] Tests (fixture PCM generated in test: 300 ms quiet noise, 1 s 440 Hz tone, 900 ms quiet): `vad start then end after 800 ms silence`; `vad max at 30 s`; `controller: full voice turn calls stt, send(voice), tts`; `speech during speaking at normal level is ignored, at ×3 level barges in`; `empty transcript → idle, no send`; `tts throws → reply still in chat, state idle`.
- [ ] FAIL → implement → PASS. Commit `feat: VAD and voice controller`.
